# Portfolio Web — Bidhun Paulose

Welcome to my personal portfolio website! 🌐  
Built with React + Vite, this is a showcase of my projects, skills, and work.

## Project Structure

- `public/` — static files (favicon, assets, etc.)  
- `src/` — main React code (components, utilities, etc.)  
- `index.html` — page entry point  
- `package.json` & `package-lock.json` — dependency and script management  
- `vite.config.js` — build and dev server configuration for Vite  
- `eslint.config.js` — linting rules to keep the code clean and consistent  

## Key Features

- Built with **React + Vite** — lightweight, fast reload, and optimal build performance  
- **ESLint** configured to keep the coding style clean  
- Modular structure, ready to expand with more pages ("About", "Projects", etc.)

## How to Run

1. Clone this repository:
````bash
git clone https://github.com/bidhunpaulose/bidhun-portfolio.git
cd bidhun-portfolio
````

2. Install dependencies:
````bash
npm install
````

3. Run the local dev server with hot reload:
````bash
npm run dev
````

4. Build for production:
````bash
npm run build
````
